# 酒馆助手 · 词条分组管理器

把聊天补全预设中的词条存成多个分组，分别批量开启或关闭。沿用酒馆主题配色，支持桌面和手机。

当前版本：**5.1.1**。

## 安装

1. 在酒馆里导出当前预设作为备份。旧版如果刚编辑过分组，请先点击酒馆的预设保存按钮。
2. 下载并导入 [在线版 JSON](https://github.com/koichole213-ui/tavern-prompt-groups/raw/refs/heads/main/prompt-groups.json)。在酒馆助手脚本库中替换原分组管理器；同一个管理器只启用一份。
3. 选择一个已保存的聊天补全预设，启用脚本。窗口标题显示当前实际运行版本。

需要酒馆助手支持 `getPreset`、`getLoadedPresetName` 和 `updatePresetWith` 预设接口。在线版会从 jsDelivr 下载对应版本的模块；网络不可用时，可改用 [离线完整代码版](https://github.com/koichole213-ui/tavern-prompt-groups/raw/refs/heads/main/prompt-groups.standalone.json)。

## 只改版本号更新

在线版导入一次后，打开酒馆助手里的脚本编辑器，只改开头这一行：

```js
const VERSION = '5.1.1';
```

将它改成已经发布的新版本号，保存，然后停用再启用脚本，或刷新酒馆。分组仍从原预设读取，不需要重新勾选。

版本必须已经存在对应的 `v版本号` 标签。填写尚未发布的版本不会产生新版，会提示加载失败。版本模块经过版本号核对后才会启动；主下载入口失败时尝试备用入口，停用后到达的下载不会启动。

## 使用

- **分组管理**：新建、重命名、删除分组，搜索词条，勾选成员后保存。删除分组只删除名单，不删除预设词条。
- **搜索**：隐藏结果中的勾选仍保留；搜索时全选／取消只影响搜索结果。
- **全部开启／全部关闭**：操作所选分组已保存的成员。成员勾选未保存时，会提醒先保存。
- **切换分组**：打开快捷面板，每组都有切换、全部开启、全部关闭。切换保持原规则：任一成员开启则全部关闭，否则全部开启。
- 分组可以同时开启；同一词条属于多个分组时，其开关状态会同时影响这些分组。
- **分组名单永久保存**到对应具名预设，仅修改分组扩展数据，不会顺手保存其他尚未保存的参数、词条内容或开关。
- **词条开关当前生效**；如需长期保留开关状态，仍需点酒馆的预设保存按钮。
- 未保存的勾选在关闭、切组或另开窗口时会提醒。窗口打开后切预设、增删词条或调整顺序，旧窗口会停止写入，需要重新打开。

名称可以包含引号、特殊字符或 `constructor`、`__proto__`。名称只作为文本显示，不会拼接到酒馆斜杠命令。损坏的分组数据不会被静默覆盖成空分组。

## 发布新版本

无需安装构建依赖，只需 Node.js 22 或更新版本。

1. 修改 `prompt-groups.js` 的功能代码。
2. 修改 `package.json` 中的 `version`，例如 `5.1.1`。
3. 运行 `npm run build`、`npm run check`、`npm test`。构建会同步源码版本、加载器和两个 JSON，并生成版本模块。
4. 提交并推送本次范围，然后创建、推送相同版本的标签，例如 `v5.1.1`。标签发布后不要改动它，下一次改动使用新版本。
5. 标签触发的 GitHub Actions 会运行检查并创建 GitHub Release，附带在线版和离线版 JSON。发布后核对下载链接和窗口版本；CDN 新标签可能需要时间传播。

用户更新时只需要修改酒馆里的 `VERSION`。本地仅改版本号、尚未发布标签，不会更新线上代码。

## 验证

`npm test` 包含 29 项核心和加载器测试：保存与保留未保存修改、精确分组匹配、预设切换和词条缺失保护、特殊名称、失败提示、主备下载、超时以及停用清理。

本地隔离浏览器还通过了 20 项界面检查，运行真实模块导入及 iframe 父页面界面，覆盖操作回归和 390×844、320×568、844×390 布局。它使用模拟酒馆接口，不代表已在所有真实酒馆版本验证。
